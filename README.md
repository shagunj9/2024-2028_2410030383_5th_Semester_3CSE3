> Capstone project for the **1-Month Artificial Intelligence Internship Programme** at **Codec Technologies Pvt. Ltd.**, completed under the National Internship Portal (AICTE, Ministry of Education).


## 📋 Overview

This project implements an end-to-end **Natural Language Processing (NLP)** pipeline that classifies text (e.g., product or movie reviews) as expressing **positive**, **negative**, or **neutral** sentiment. It was built as the capstone deliverable for a one-month AI internship, consolidating concepts from Python foundations, machine learning, and NLP.

## 🎯 Objectives

- Understand and apply core NLP concepts — tokenisation, text cleaning, normalisation
- Preprocess raw textual data into a numerical form suitable for ML models
- Build and train a classification model to predict text sentiment
- Evaluate performance using accuracy, precision, recall, and F1-score
- Gain hands-on experience with NumPy, Pandas, Scikit-learn, NLTK/SpaCy

## 🏗️ Architecture

| Stage | Description |
|---|---|
| Data Input | Raw text dataset (reviews / feedback / comments) |
| Preprocessing | Lowercasing, punctuation & stop-word removal, tokenisation, stemming/lemmatisation |
| Feature Extraction | Bag-of-Words / TF-IDF vectorisation |
| Model | Logistic Regression (Scikit-learn) |
| Evaluation | Accuracy, precision, recall, F1-score, confusion matrix |
| Output | Predicted sentiment label (Positive / Negative / Neutral) |

## 🛠️ Tech Stack

- **Language:** Python 3
- **Environment:** Jupyter Notebook / Google Colab
- **Data Handling:** NumPy, Pandas
- **Visualisation:** Matplotlib, Seaborn
- **NLP:** NLTK, SpaCy
- **Machine Learning:** Scikit-learn (Logistic Regression, TF-IDF Vectorizer)
- **Deep Learning (optional extension):** TensorFlow / Keras
